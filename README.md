# OpenShelf Digital Library

OpenShelf is a beginner-friendly Digital Library frontend project. It demonstrates how HTML, CSS and JavaScript can be combined to create a responsive website for exploring a sample collection of learning resources.

## Features

- Responsive layout for desktop, tablet and mobile screens
- Sample book catalogue with title, author, category and description
- Search books by title or author
- Filter books by category
- View a book's details in a dialog
- Link to search for a title on Open Library
- Empty-state message when no books match the search

## Technologies Used

- HTML for page structure
- CSS for styling, Flexbox, CSS Grid and media queries
- JavaScript for displaying books, searching, filtering and opening book details
- Visual Studio Code for development

## How to Run the Project

No installation or backend server is required.

## Project Structure

```text
digital-library-frontend/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

- `index.html` contains the page sections and the elements used by the interface.
- `style.css` controls colours, spacing, book cards, layout and responsive behaviour.
- `script.js` contains sample book data and functions for rendering, searching, filtering and displaying book details.
- `README.md` explains the project and how to run it.

## Limitations

This is a frontend demonstration. The sample catalogue is stored in JavaScript, not a database. It does not include user accounts, a borrowing system, or file uploads. The Open Library link searches for a title; it does not guarantee that a free digital copy is available.

## Possible Future Improvements
